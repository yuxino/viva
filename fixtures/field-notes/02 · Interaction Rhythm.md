# Interaction rhythm

An interface feels fast when each action has one visible consequence.

## Open

Choose a folder and continue where you stopped. The file tree is navigation,
not decoration.

## Write

The source stays readable. The preview answers immediately. Switching views
does not reset the cursor or move the thought somewhere else.

## Save

`Command S` writes atomically to the original file. Viva shows the result in
plain language: **Saved locally**.
