# A quiet place for unfinished thoughts

Good tools do not ask for attention. They return it.

Viva keeps the working file, its structure, and the finished page in one calm
field of view. Nothing leaves this computer, and nothing appears unless it can
actually be used.

## Design should disappear

The editor holds the structure while the preview keeps the rhythm of the page
visible. A folder is still a folder. A Markdown file remains plain text.

> Keep the sentence alive. Let the interface become quiet around it.

## A small working agreement

- Local files, always
- Preview without losing the cursor
- Save before anything gets clever
- Publish only when the words are ready

The best state is not “done.” It is easy to return to.
