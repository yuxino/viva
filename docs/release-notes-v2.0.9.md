## English

Viva 2.0.9 improves installation and keeps unsaved documents safe during updates.

- Windows setup now uses Viva's own high-resolution character artwork, a clearer layout, and English, Simplified Chinese, and Japanese text. The optional GitHub link opens only when clicked.
- Save open documents before installing an update or restarting Viva. The updater checks again after downloading so a new unsaved draft cannot be lost when Windows closes the app to finish installation.
- Updates continue to download inside Viva with real progress and signature verification. Windows reopens the app after installation; macOS waits for **Restart and finish update**.

Open **Appearance and background → Software Update** in Viva 2.0.7 or later.
Version 2.0.6 and earlier need one manual installation because their updater is
absent or lacks a required permission.

Downloads cover macOS Apple silicon and Windows x64. The updater archives have
independent signatures; macOS builds remain ad-hoc signed and not notarized,
and Windows installers are not Authenticode-signed. Use the normal system Open
flow if prompted. Automated checks and Windows installer-preview screenshots
do not establish a complete cross-version update on a user's device.

## 中文

Viva 2.0.9 改善安装界面，并在应用更新时保护未保存的文档。

- Windows 安装程序采用 Viva 专属高清人物、更清楚的排版，以及英文、简体中文和日文文案。GitHub 链接只在主动点击时打开。
- 安装更新或重启 Viva 前需要先保存打开的文档。下载结束后会再次检查，避免 Windows 关闭应用完成安装时丢失新产生的草稿。
- 更新继续在 Viva 内下载，显示真实进度并校验签名。Windows 安装完成后重新打开应用；macOS 等待点击“重新启动并完成更新”。

Viva 2.0.7 及以后版本可打开“外观与背景 → 软件更新”。2.0.6 及更早版本由于缺少更新器或必要权限，需要先手动安装一次。

提供 macOS Apple 芯片和 Windows x64 下载。更新包有独立签名；macOS 仍使用临时签名，未经 Apple 公证，Windows 安装包未做 Authenticode 签名。如系统提示，请使用正常的手动打开流程。自动化检查和 Windows 安装界面预览截图不代表已完成用户设备上的完整跨版本更新验收。
